# dsh-autoPID 调参规则（内置规则文件）

这份文件是**给 AI 看的操作手册**，不是给单片机看的。插件启动时从本目录读取，
`autopid_tuning_rules` 工具会把它连同当前权重一起返回。
**改这份文件不用重启 DSH，但改完最好重新调用一次 `autopid_tuning_rules` 确认读到的是新版。**

---

## 一、四个权重（设置页里是滑块，0~100）

| 键 | 含义 | 当前值 |
|---|---|---|
| `tuneKpOsc` | 对 **Kp 引起的高频抖动** 的关注度 | {{kpOsc}} |
| `tuneKiOsc` | 对 **Ki 引起的低频摆动 / 超调** 的关注度 | {{kiOsc}} |
| `tuneSpeed` | 对 **响应速度（上升时间）** 的关注度 | {{speed}} |
| `tuneSteady` | 对 **稳态均值 / 稳态误差** 的关注度 | {{steady}} |

四个权重是**打分权重**，不是互相排斥的档位。每个候选参数组合都按下式算一个分：

```
score = 100
      - tuneSteady × steadyErr%      / 100
      - tuneSpeed  × riseTime_ms     / 100
      - tuneKpOsc  × rippleRatio     / 100
      - tuneKiOsc  × swingRatio      / 100
```

其中

- `steadyErr%`：稳态均值相对目标的百分比误差（取绝对值）
- `riseTime_ms`：上升时间，优先用到 63% 的时间，算不出就用 30%~70% 段折算
- `rippleRatio`：**稳态段高频抖动** —— 平滑后尾段峰峰值 ÷ 目标值 × 100
- `swingRatio`：**低频摆动/超调** —— 超调百分比 + 稳态段缓慢漂移幅度（÷ 目标 × 100）

> 权重为 0 表示"这一项完全不看"，100 表示"这一项最要紧"。
> **分数只是排序工具，不能替代物理约束** —— 见第五节。

## 二、必须先知道的机理（踩过坑，别再犯）

1. **这是增量式 PID**：`output += Kp·(e−e_prev) + Ki·e + …`
   - 匀速段 `e−e_prev ≈ 0` → **Kp 对稳态误差几乎没作用**
   - **稳态误差靠 Ki 消**，Kp 只影响动态（跟得快不快、抖不抖）
   - 所以「追不上目标」先去加 Ki，别急着加倍 Kp
2. **上位机发的系数还要乘缩放常数**（本仓库默认 `PIDInc_Kp=1.0 / Ki=0.03 / Kd=0.3`）：
   发 `SET 20 30 0` 实际是 Kp=20、Ki=0.9、Kd=0。
   报结果时**两个数都给**（下发的数字 + 实际生效值），否则下次没人算得回来。
3. **量化噪声会伪装成振荡**：速度通常是整数计数，尾段纹波 2~3 个计数就够造出
   20~45 Hz 的"假振荡"。**判断振荡前必须先做 30ms 滑动平均**，并看峰峰值是否
   明显大于 1~2 个计数。
4. **目标自己会变**（示例固件里每 3 秒换一次目标）——这是刻意留的激励信号，
   按"目标变化"切段分析，不要当成噪声或故障。

## 三、调参流程（照这个顺序，别跳）

**第 0 步：安全前置**

- 每轮实验前先 `STOP`，改完参数再 `RESET`，最后 `START`
- 拿不准就先把车架起来空转
- **单步放大不超过 2 倍**；想试极限值必须**先问操作者**，并说明可能出现的现象

**第 1 步：先定 Ki（稳态），Kp 给一个保守值**

- 从 `Kp=20 / Ki=30 / Kd=0` 这一组起步（智能车实测很稳）
- 看 `steadyErr%`：还差得远就加 Ki，一步 ×2；出现低频摆动就往回退

**第 2 步：再调 Kp（动态）**

- 在 Ki 固定的情况下把 Kp 往上走：20 → 40 → 80，**每步只动一档**
- 关注 `riseTime_ms`（变小 = 变快）和 `rippleRatio`（变大 = 开始抖）
- 出现"更快但逼近时来回蹭"（到 90% 反而变慢）就是**过头了**，退回上一档

**第 3 步：最后看 Kd（抑制超调）**

- 只有 `swingRatio` 明显时才加 Kd，且从小值开始
- Kd 太大会放大测量噪声 → `rippleRatio` 飙升，这时宁可退回

**第 4 步：按权重收口**

- 把历次实验的记录拿出来，用第一节的公式算分，取分最高的那组
- **但要同时报告"稳健性"**：如果最高分那组离失效边界只差一档，建议选保守的那组

## 四、每轮实验必须记录（少一项就没法比较）

| 项 | 例 |
|---|---|
| 下发参数 | `SET 20 30 0`（实际 Kp=20 / Ki=0.9 / Kd=0） |
| 采集窗口 | `since=1793542616`，约 20 秒 |
| 稳态误差 | 左 -0.8% / 右 -1.1% |
| 上升时间 | 到 63% 用 46 ms |
| 高频抖动 | 尾段峰峰 2.2 计数 |
| 低频摆动/超调 | 超调 5.6%，无缓慢漂移 |
| 是否失效 | 否 |

**失效的判据**（任一条成立就算"这一档不能用"）：
速度长时间贴 0、目标追不到一半、纹波峰峰超过目标的 15%、驱动明显发热或有异响。

## 五、硬性红线（权重再高也不能越）

1. **不允许在真机上一次把增益放大超过 2 倍**（哪怕是为了找边界）
2. **不允许在带载、贴地、有人的场合做极限实验**；能空转就空转
3. **出现异常立刻 STOP**，先把参数退回上一组安全值，再解释
4. **没测过的参数不许说"应该没问题"** —— 没数据就说没数据
5. 权重只决定"取舍方向"，**不改变安全约束**：`tuneSpeed=100` 也不代表可以越界冲刺

## 六、给操作者的汇报格式（三段，别写小作文）

1. **这轮试了什么**：参数 + 窗口
2. **数据怎么说**：稳态/上升/抖动/摆动 四个数，外加"有没有失效"
3. **建议下一步**：改哪个参数、改到多少、为什么（引用权重）
